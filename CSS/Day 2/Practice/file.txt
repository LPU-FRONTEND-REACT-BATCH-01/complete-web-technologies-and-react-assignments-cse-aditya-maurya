============================================================
CSS UNITS 
=====================

1. ABSOLUTE UNITS

---

These are fixed units.

## px  -> pixels

Most used unit
Fixed exact size

Example:
width: 100px;

## cm  -> centimeter

Real-world cm size
Rarely used in screen design

Example:
width: 5cm;

## mm  -> millimeter

1cm = 10mm

Example:
width: 20mm;

## in  -> inch

1in = 96px

Example:
width: 2in;

## pt  -> points

Mostly used in print / PDF
1pt = 1/72 inch

Example:
font-size: 12pt;

## pc  -> pica

1pc = 12pt

Example:
font-size: 2pc;

============================================================
2) RELATIVE UNITS
=================

These depend on parent, root, viewport, or font.

## em

Relative to current element font-size

Example:
font-size: 2em;

If parent = 16px
2em = 32px

## rem

Relative to root html font-size

Example:
font-size: 2rem;

If html = 16px
2rem = 32px

## %

Relative to parent size

Example:
width: 50%;

Means half of parent

## vw

Viewport width
1vw = 1% of screen width

Example:
width: 50vw;

## vh

Viewport height
1vh = 1% of screen height

Example:
height: 100vh;

## vmin

Smaller of vw or vh

Example:
font-size: 5vmin;

## vmax

Larger of vw or vh

Example:
font-size: 5vmax;

## ch

Width of "0" character

Best for text input width

Example:
width: 20ch;

## ex

Height of x letter

Rarely used

Example:
line-height: 2ex;

============================================================
3) BEST USE CASES
=================

## px

exact fixed size

## em

button padding, text relative scaling

## rem

full responsive design system

## %

layouts and responsive widths

## vw / vh

full screen sections

## cm / mm / in

print design only

============================================================

=============================

Named Colors – Predefined color names like red, blue, green.
Hexadecimal (Hex) – #RRGGBB or #RGB, uses hexadecimal digits.
RGB – rgb(r, g, b), values 0–255 for red, green, blue.
RGBA – rgba(r, g, b, a), RGB + alpha (transparency 0–1).
HSL – hsl(h, s%, l%), hue, saturation, lightness.
HSLA – hsla(h, s%, l%, a), HSL + alpha (transparency 0–1).
CurrentColor – Uses the current text color.
Transparent – Fully transparent color.
CSS System Colors – Colors that match OS interface elements (deprecated).


CSS Gradients

Linear Gradient – Color transition in a straight line (top→bottom, left→right, diagonal).
background: linear-gradient(to right, red, yellow);
Radial Gradient – Color transition from a center point outward in a circular or elliptical shape.
background: radial-gradient(circle, red, yellow) (circle at top,left,right,bottom,top left,top right);
Conic Gradient – Color transition around a center point like a pie chart.
background: conic-gradient(red, yellow, green);
Repeating Gradients – Repeats linear, radial, or conic gradients for patterns.
background: repeating-linear-gradient(45deg, red, yellow 20px);
