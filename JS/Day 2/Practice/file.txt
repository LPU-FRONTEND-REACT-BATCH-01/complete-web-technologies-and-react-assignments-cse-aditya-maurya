JAVASCRIPT MAIN FUNCTION TYPES - SHORT NOTES

1) Function Declaration
A normal named function created using the function keyword.
Example:
function greet() {
  console.log("Hello");
}
Note: Hoisted, so it can be called before definition.

2) Function Expression
A function stored inside a variable.
Example:
const greet = function() {
  console.log("Hello");
}
Note: Useful when assigning functions to variables.

3) Arrow Function
A shorter syntax introduced in ES6.
Example:
const greet = () => {
  console.log("Hello");
}
Note: Best for short functions and callbacks.

4) Anonymous Function
A function without a name.
Example:
setTimeout(function() {
  console.log("Hi");
}, 1000);
Note: Mostly used as callback functions.

5) Named Function Expression
A function expression with its own internal name.
Example:
const greet = function sayHello() {
  console.log("Hello");
}
Note: Helpful in debugging.

6) IIFE (Immediately Invoked Function Expression)
A function that runs immediately after being created.
Example:
(function() {
  console.log("Runs instantly");
})();
Note: Used for private scope.

7) Callback Function
A function passed as an argument to another function.
Example:
function process(callback) {
  callback();
}
Note: Common in asynchronous programming.

8) Higher-Order Function
A function that accepts another function or returns one.
Example:
function outer() {
  return function inner() {};
}
Note: Used in map, filter, reduce.

9) Constructor Function
A function used to create objects with new.
Example:
function Person(name) {
  this.name = name;
}
Note: Used in old-style object creation.

10) Generator Function
A function that can pause and resume using yield.
Example:
function* gen() {
  yield 1;
}
Note: Useful for iterators.

11) Async Function
A function that works with promises using async/await.
Example:
async function load() {
  return "Done";
}
Note: Best for API calls and async tasks.

12) Recursive Function
A function that calls itself.
Example:
function fact(n) {
  return n === 1 ? 1 : n * fact(n - 1);
}
Note: Used in factorial, tree traversal.

13) Method Function
A function inside an object.
Example:
const user = {
  greet() {
    console.log("Hello");
  }
}
Note: Used as object behavior.
